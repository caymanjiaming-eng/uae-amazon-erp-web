# UAE Amazon ERP Web

Public interface only. Import a UAE-VC .xlsx workbook in the browser to view Summary, Monthly Sale, Sales, Inventory, Traffic, Monthly-Traffic and Return Rate.

Saved Excel results and recalculation from the raw sheets are separate modes. Files stay in the current tab and are not uploaded. Refreshing requires importing again.

The separate ads.html page preserves the existing advertising workspace and accepts a local ERP HTML snapshot.

No operating datasets, credentials, analytics services or external libraries are hosted here.
