# UAE Amazon ERP Web

Public interface only. No operating datasets, database files, account credentials or private repository history are included.

Open the GitHub Pages site and select the local ERP `index.html` snapshot generated by the private project. The file is read in the browser; it is not uploaded. This version accepts ERP HTML snapshots, not raw Amazon CSV/XLSX reports.

Business data stays in the current tab. Action records are saved in browser localStorage; export them before clearing browser storage.
